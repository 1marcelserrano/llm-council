# Contribuir

Obrigado pelo interesse. Esta skill é open-source sob licença MIT.

## Como propor mudanças

1. Faça um fork e crie um branch a partir de `main`.
2. A fonte de verdade do comportamento é `skills/llm-council/SKILL.md`. Comece por lá.
3. Mantenha o frontmatter (`name`, `description`) intacto.
4. Use Conventional Commits (`feat:`, `fix:`, `docs:`…).
5. Abra um PR descrevendo o que muda e por quê.

## Princípios

- **Voz direta.** Frases curtas, voz ativa, zero floreio. Sem léxico inflado, sem paralelismo negativo.
- **Não fabrique números.** O valor vem do método (conselho + revisão cruzada), não de marketing.
- **O mecanismo é a tensão + a revisão anônima.** Conselheiro morno é conselheiro inútil. Mudanças que diluem isso não entram.

Dúvida ou ideia? Abra uma issue.
